📮 Postman da Sinab Ko'rish (1-Click Import)

To'liq tayyor Postman Collection (v2.1) va Environment fayllari. Postman ilovasida Import tugmasini bosib fayllarni yuklang — barcha 14 ta modul, avtomatik JWT auth scriptlari va test JSON payloadlari tayyor!

🔑 API Autentifikatsiya (JWT Bearer Token)

Barcha /api/admin/* yo'llari uchun HTTP sarlavhasida (Headers) Bearer Token uzatilishi shart:

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
🔐 01. Autentifikatsiya va Profil (Authentication)
Foydalanuvchilarni ro'yxatdan o'tkazish, tizimga kirish va JWT tokenni yangilash.
POST /auth/login Tizimga kirish va JWT token olish

Request Body (JSON)

ParametrTurMajburiyTavsif
emailstringHaFoydalanuvchi emaili
passwordstringHaMaxfiy parol
{ "email": "buxgalter@sapar.uz", "password": "password123" }

📄 04. Sotuvlar va Hisob-fakturalar (Invoices & TTN)
Hisob-faktura yaratish, QQS 12% hisoblash, yetkazib berish yukxatlari va kredit-notalar.
GET /admin/invoices/next-number Keyingi navbatdagi hisob-faktura raqamini generatsiya qilish
POST /admin/invoices Yangi sotuv hisob-fakturasini rasmiylashtirish

📦 05. Mahsulotlar Katalogi va MXIK (Products)
17-xonali MXIK/IKPU kodli mahsulotlar, shtrix-kodlar, narxlar va zaxiralar.
GET /admin/productsrecent Tezkor mahsulot qidirish dropdown (Shtrix-kod / Artikul)
POST /admin/products Yangi mahsulot yaratish
🏛️ 06. O'zbekiston 21-son BHMS Buxgalteriyasi (Accounting)
Bosh kitob, provodkalar, Oborotno-saldo vedomost, 1-Shakl (Balans) va 2-Shakl (P&L).
GET /admin/accounting/bhms/oborotka-trial-balance Aylanma vedomost (Oborotka) hisoboti
GET /admin/accounting/bhms/form1-balance-sheet Buxgalteriya Balansi (1-Shakl Davlat Hisoboti)
GET /admin/accounting/bhms/form2-profit-loss Moliyaviy Natijalar To'g'risida Hisobot (2-Shakl)
POST /admin/accounting/journal-entries Yangi buxgalteriya provodkasini kiritish (Manual Entry)
📑 07. Davlat Soliq Qo'mitasi Hisobotlari (Soliq Filing)
QQS 12% (Form 10006_29), JShODS & Ijtimoiy soliq (Form 11101_14) va Aylanma soliq (Form 10104_18).
GET /admin/accounting/reports/soliq-qqs QQS 12% Oylik Soliq Deklaratsiyasi (Form 10006_29)
GET /admin/accounting/reports/soliq-jshods JShODS va Ijtimoiy Soliq Deklaratsiyasi (Form 11101_14)
🔏 08. E-IMZO va Didox E-Faktura (Digital Signature)
Didox/Factura/Soliq operatorlari orqali PKCS#7 elektron raqamli imzo va e-faktura almashinuvi.
POST /admin/eimzo/sign-document Hujjatni E-IMZO PKCS#7 bilan tasdiqlash va imzolash
POST /admin/e-documents/send-didox Didox.uz / Soliq tizimiga e-fakturani yuborish
💳 09. O'zbekiston To'lov Tizimlari (Payment Gateways)
Payme Business, Click Merchant va Uzum Pay orqali hisob-faktura to'lovlarini qabul qilish.
POST /admin/gateways/payme/generate-link Payme to'lov havolasini (QR) shakllantirish
POST /admin/gateways/click/generate-link Click Merchant to'lov havolasini shakllantirish
